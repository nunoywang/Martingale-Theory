## Overview

This project is an introduction to discrete-time martingale theory, exploring their fundamental properties, convergence theorems, and applications.

The report starts with the concept of conditional expectation, which lays the foundation to define martingales, submartingales, and supermartingales. Subsquently, their convergence properties are explored, namely the role of the upcrossing inequality in establishing almost sure convergence, along with the integrability conditions necessary for convergence in $L^p$. Moreover, the report also explores optional stopping theorems.

Lastly, an application of these concepts to Galton–Watson branching processes is presented.

## Contents

1. **Conditional Expectation**
   - Definition of conditional expectation and its fundamental properties

2. **Martingales, Submartingales, and Supermartingales**
   - Definition and some transformations
   - Predictable processes and stopping times
   - Upcrossing inequality and the martingale convergence theorem

3. **Integrability Conditions for Martingale Convergence**
   - Doob's inequalities and convergence in $L^p$, for $p>1$
   - Uniform integrability and convergence in $L^1$

4. **Optional Stopping Theorems**
   - Conditions under which expected-value properties are preserved for randomly stopped martingales

5. **Branching Processes**
   - Application to Galton-Watson process

6. **Appendices**
   - Additional proofs and supporting results from measure theory and probability
